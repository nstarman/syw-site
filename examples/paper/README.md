# Example paper

A synthetic showyourwork paper for syw-site's tests and documentation: a helix, three numbers, two
figures (one with two panels) and a figpress-apps webapp (`webapps/helix/`). Not real science.

CI copies it into a fresh git repository, runs `syw-site init --repo nstarman/syw-site-example`,
writes `docs/syw-site.yml`'s webapp entry, and runs `syw-site build`.
